# Bob IDE — Features & Configuration

Explore Bob IDE features and configuration to enhance working with Bob.

| Feature | Description | Docs |
|---------|-------------|------|
| **Chat interface** | Primary workspace for natural language prompts, slash commands, auto-approval. | https://bob.ibm.com/docs/ide/features/chat-interface |
| **Modes** | Specialized personas that tailor Bob's behavior for specific tasks. | https://bob.ibm.com/docs/ide/features/modes |
| **Custom modes** | Create your own modes (global or project-specific). | https://bob.ibm.com/docs/ide/configuration/custom-modes |
| **Subagents** | Handle focused, self-contained tasks in isolated contexts without polluting main conversation. | https://bob.ibm.com/docs/ide/features/subagents |
| **Auto-approve** | Eliminate repetitive prompts (read/write/execute). Increases security risk — configure safely. | https://bob.ibm.com/docs/ide/features/auto-approving-actions |
| **Custom rules** | Influence how Bob responds (coding style, docs, decisions). | https://bob.ibm.com/docs/ide/configuration/rules |
| **MCP servers** | Extend Bob's capabilities via external tools/services (Model Context Protocol). | https://bob.ibm.com/docs/ide/configuration/mcp/mcp-in-bob |
| **Ignoring files** | `.bobignore` file controls which files Bob can access. | https://bob.ibm.com/docs/ide/configuration/bobignore |
| **Context mentions** | Reference specific project elements with `@` for efficient assistance. | https://bob.ibm.com/docs/ide/features/context-mentions |
| **Security guidelines** | Bob has coding/system interaction capabilities — follow safety guidelines. | https://bob.ibm.com/docs/ide/security/bob-security-guidance |
| **Bob tips** | Real-time AI code-quality detection and refactoring suggestions. | https://bob.ibm.com/docs/ide/features/bob-tips |
| **Rollback** | Automatically version workspace files during AI tasks; recover from unwanted changes. | https://bob.ibm.com/docs/ide/features/rollback |
| **Code actions** | AI quick fixes, refactorings, code explanations via lightbulb icons / context menus. | https://bob.ibm.com/docs/ide/features/code-actions |
| **Code reviews** | Built-in Review workflow for AI-powered code reviews before commit. | https://bob.ibm.com/docs/ide/features/code-reviews |
| **Commit messages** | Generate meaningful commit messages automatically. | https://bob.ibm.com/docs/ide/features/commit-messages |
| **Pull requests** | Generate PRs and PR descriptions from the IDE. | https://bob.ibm.com/docs/ide/features/pull-requests |
| **Enhance prompt** | Sparkles icon in chat input refines requests. | https://bob.ibm.com/docs/ide/features/enhance-prompt |
| **Literate coding** | Write code with AI help using natural-language comments in the editor. | https://bob.ibm.com/docs/ide/features/literate-coding |
| **Skills** | Reusable instruction sets for specialized workflows. | https://bob.ibm.com/docs/ide/features/skills |
