# Bob IDE — Install & Login

Bob IDE is **required** for this hackathon. You must use it for the project as core evidence of Bob usage.

## Install

- Follow the Bob IDE installation instructions:
  https://bob.ibm.com/docs/ide/getting-started/install
- **Version note**: IDE v1.0.3 and v2.0.0 will stop working on **September 30, 2026**.
  - If on v1.0.3 → upgrade to the latest v2.0.x.
  - If on v2.0.0 → upgrade to **v2.0.2 or later**.

## Sign in

- To use Bob IDE you must sign in using your **hackathon registration email**.
- An **IBMid** is required to authenticate.
  - Create one: https://www.ibm.com/account/reg/us-en/signup?formid=urx-19776
- Open Bob IDE → select **Log in to Bob** → complete IBMid auth in browser.
- Once authenticated, the Bob chat interface appears.

## Important — correct account

- If you have access to multiple Bob accounts, select the **hackathon-provisioned instance named `ibm-coding-challenge-uat (region: us-east)`** to avoid consuming Bobcoins from your personal account.
- Switch via Settings icon → Settings tab → General → team.

## Firewall note

- If you experience outbound network issues, configure firewall rules:
  https://bob.ibm.com/docs/ide/troubleshooting/ts-firewall-rules
