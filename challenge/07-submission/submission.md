# Submission — Deliverables & Bob Task Session Summary

## Requirement

**Each participant** must upload all relevant **Bob task session summary screenshots** as part of the project submission. These must be included in your **final code repository** as a **submission deliverable**.

## Steps to complete

1. Create a folder named **`bob_sessions`** in your project submission code repository.
2. In Bob IDE's chat interface, select **Tasks** to display the task list.
3. Select a task related to your project submission — it opens in the chat panel.
   - Confirm you are in the correct project workspace.
   - If submission includes tasks from multiple workspaces, select **All** to view across workspaces.
4. Select the **task header** — a task session consumption summary is displayed.
5. **Take a screenshot** of the task session consumption summary.
   - Save in **PNG** format where possible for better text clarity.
   - Use a clear filename: **team name + task number + short task description**.
   - Example: `teamalpha_task01_login_flow_summary.png`
6. Repeat for **all** tasks related to your project submission.
7. **Upload all screenshots** into the `bob_sessions` folder in your code repository.

## Final check before submitting

- [ ] Project final code repository includes the **`bob_sessions`** folder
- [ ] Contains all required task session summary screenshots relevant to the project solution
- [ ] Each screenshot named clearly (team + task + description)
