# Bob Shell (Optional)

Bob Shell brings IBM Bob's AI capabilities to the **command line** — same context awareness and reasoning-focused approach, optimized for shell environments and automated processes.

## Install

- Follow the install instructions: https://bob.ibm.com/docs/shell/getting-started/install-and-setup
- **Upgrading from 1.0.x**: Bob Shell 2.0.0 requires a **fresh install** (no automated upgrade path). Existing settings/config are preserved.

## Authentication

- Same login entry point as all Bob clients: **bob.ibm.com/login**
- More: https://bob.ibm.com/docs/shell/getting-started/install-and-setup#authentication

## Sessions

- **Interactive**: conversational interface in the terminal for real-time dev assistance.
  https://bob.ibm.com/docs/shell/getting-started/start-bobshell-interactive
- **Non-interactive**: use Bob Shell directly from the CLI without entering interactive mode. Good for automation, scripting, batch processing.
  https://bob.ibm.com/docs/shell/getting-started/start-bobshell-non-interactive

## Configuration

- Match your workflow preferences: https://bob.ibm.com/docs/shell/configuration/configuring

## Tools

- Specialized tools to read files, edit code, run commands, interact with your dev environment.
  https://bob.ibm.com/docs/shell/core-concepts/tools

## Features

- **Slash commands**: custom slash commands to automate workflows & standardize team practices.
  https://bob.ibm.com/docs/shell/features/slash-commands
- **Modes**: specialized personas tailoring Bob's behavior.
  https://bob.ibm.com/docs/shell/features/modes
