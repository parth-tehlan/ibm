# Theme, Rules & Policies

## Theme

**Build with purpose using IBM Bob 2.0**

Create a solution that improves a specific developer workflow (onboarding, debugging, code review, testing, application maintenance, or release/deployment).

## Key rules

- Build a **working prototype** using **IBM Bob IDE**.
- **IBM Bob IDE is required** and must be a **core component** to be eligible for judging.
- Work on a **real or sample project**.
- Demonstrate **impact**: productivity gains, reduced manual effort / errors / rework, or shorter task time.
- **Bob Shell is optional**.
- **watsonx Orchestrate and watsonx.ai are optional** additions.

## Technology policy

- Any framework/technology is allowed as long as it adheres to product usage policies.
- The solution must showcase **IBM Bob IDE** as a core component for judging eligibility.
