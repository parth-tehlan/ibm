# Data & Dataset Guidelines

Participants are **required to bring their own datasets** to build the solution aligned to their use case.

## Best practices

- Participants are **responsible for ensuring data is compliant**.
- **Public website data** may be used **if the terms allow commercial use** — keep a list of the websites you use.
- Do **NOT** use data/assets containing **company confidential data**, or any data without the data owner's permission. Get approval where needed.
- Do **NOT** use **client data**.
- Do **NOT** use data containing **personal information (PI)**.
- Do **NOT** use data obtained from **social media**.

## Summary checklist

- [ ] Compliant data
- [ ] Public-site terms allow commercial use (list tracked)
- [ ] No company-confidential data
- [ ] No client data
- [ ] No personal information (PI)
- [ ] No social media data
