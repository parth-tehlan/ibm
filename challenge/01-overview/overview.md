# Hackathon Overview & Expectation

## The expectation

In this hackathon, you will design and build a **working prototype** using **IBM Bob IDE**, aligned to the theme:

> **Build with purpose using IBM Bob 2.0**

Create a solution that improves a specific **developer workflow**, such as:
- Onboarding
- Debugging
- Code review
- Testing
- Application maintenance
- Release and deployment

## Steps to follow

1. **Clearly define a problem** where time, effort, or errors are too high today.
2. Using **IBM Bob 2.0**, build a **working prototype** on a real or sample project that demonstrates a full solution to improve the specified workflow.
3. Leverage features like **Agent mode, parallel tasks, subagents, and document understanding** to manage and improve **multiple steps**, not just assist with coding.
4. Clearly demonstrate impact: show how your solution **increases productivity, reduces manual effort, errors, and rework, or significantly shortens the time** required to complete tasks.

## Requirements

- **Upload all relevant Bob IDE task session summary screenshots** to your code repository as evidence of Bob usage. See `07-submission/`.
- **Optional**: Use watsonx products (Orchestrate and/or watsonx.ai). See `08-watsonx/`.
- **Dataset**: Bring your own dataset aligned to your use case. See `10-data-guidelines/`.

## Notes on other technologies

- You may use **any framework or technology**, as long as you adhere to product usage policies.
- **Eligibility for judging**: Your solution **must showcase IBM Bob IDE as a core component**.
